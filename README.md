# Terminal Sudoku

Claude Code-inspired terminal Sudoku game.

## Run

```
uv run sudoku
```

## Commands

| Key | Action |
|-----|--------|
| arrows / hjkl / wasd | Move cursor |
| 1-9 | Enter number |
| 0 / x / Backspace | Clear cell |
| n | Toggle notes mode |
| u | Undo |
| r | Redo |
| H | Hint |
| N | New game |
| q / Esc | Quit |
